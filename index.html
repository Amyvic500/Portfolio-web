03 — Featured Project

CareQueue Platform

Latest Project

CareQueue — Healthcare Queue Management System

A microservices-based healthcare queue management platform built to digitise and streamline patient flow in public health clinics. The system handles real-time queue management, AI-powered wait time predictions, SMS notifications via Twilio, and a staff admin dashboard — deployed across staging (Render.com) and production (AWS EC2) environments.

Category Healthcare Tech / Microservices Platform
My Role DevOps Engineer
Stack Docker · Docker Compose · Nginx · Flask · React · PostgreSQL · Redis · Celery · AWS EC2 · Render.com
Live Backend nexus-carequeue-backend.onrender.com

What I Did

Wrote 4 Dockerfiles — Flask/Gunicorn backend, React/Nginx multi-stage frontend, FastAPI AI service & dev variants
Orchestrated 6 containers with Docker Compose — Frontend, Backend, Celery Worker, AI Service, PostgreSQL & Redis
Configured Nginx reverse proxy inside the frontend container routing /api/ calls to the backend with WebSocket upgrade support
Set up PostgreSQL health checks ensuring dependent services only start after the database is ready
Wired Redis + Celery for async SMS notification task queuing via Twilio integration
Built dev/production environment split using Docker Compose overrides with hot reload volumes for local development
Managed two deployment environments — Render.com (staging) and AWS EC2 (production)
Implemented RBAC, NDPR compliance & automated vulnerability scanning across the stack
