02 — Featured Project

CareQueue Platform

Latest Project

CareQueue — Healthcare Queue Management System

A microservices-based healthcare queue management platform built to digitise and streamline patient flow in public health clinics. The system handles real-time queue management, AI-powered wait time predictions, SMS notifications via Twilio, and a staff admin dashboard — deployed across staging (Render.com) and production (AWS EC2) environments.

Category Healthcare Tech / Microservices Platform
